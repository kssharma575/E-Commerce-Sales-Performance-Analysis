# Sales-Performance-Analysis

**Overview** : This project analyses e-commerce sales data to understand overall sales performance, profitability, product category performance, customer segments, and regional trends.

The objective is to transform raw sales data into meaningful business insights using Excel.

**Technologies Used** : Microsoft Excel

**Steps**
1. Data Cleaning: Removed duplicates from the dataset.
2. Data Transformation: Created custom columns to extract additional information.
3. Data Visualization: Utilized PivotTables, Charts, and Graphs to visually summarize the data.
4. Dashboard Creation: Built an Excel dashboard with slicers for user interactivity.

**Dataset Overview**
The workbook's Sales Data sheet contains 51,290 rows and 21 columns covering order dates in 2015.

Key fields include Order ID, Order Date, Ship Date, Product Category, Product, Sales, Quantity, Discount, Profit, Segment, Country, Region, and Ship Mode.

**Key Performance Indicators**
 * Total Sales
 * Total Profit
 * Total Quantity Sold
 * Total Orders
 * Profit Margin
 * Average Order Value

**Key Findings**
* Fashion is the largest product category by sales, contributing approximately 65% of total recorded sales.
* Consumer is the largest customer segment by sales, contributing approximately 51.5%.
* December recorded the highest monthly sales, while February recorded the lowest.
* Central was the highest-sales region in the dataset.
